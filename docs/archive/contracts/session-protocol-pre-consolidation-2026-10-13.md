# Session protocol v1 proof

The authoritative wire envelope is [`protocol/session-v1.schema.json`](../protocol/session-v1.schema.json). The Rust client and Python fixture exchange UTF-8 newline-delimited JSON over a same-UID Unix socket. Frames are bounded at 1 MiB and commands at 64 KiB. `hello` binds protocol major, exact release, and project key before any request. The fixture demonstrates `snapshot`, `command`, `command_get`, and cursor-based `events_read` with application-owned command IDs, stale-state refusal and identical-command replay. The fixture is disposable test code, not a service or workflow authority.

Command outcomes mean: `accepted` is durably admitted by a real service, `rejected` did not mutate state, and `applied` denotes a completed application transition. Transport loss never means execution failed. The Rust outbox stores exact pending command bytes as 0600 files, scoped to the client project; only a matching backend acknowledgement removes them. A restart replays the same ID and body. A real project service must commit command outcome and event in one database transaction and answer `command_get` after lost replies. A coordinator proposal may request an action, but cannot label itself as an operator answer or approval.

The Rust client uses separate bounded command and event channels. The event poller requests at most 64 records and blocks when its 16-slot UI channel fills. The UI holds at most 200 visible history items and 2 MiB; older records remain in the backend. Pane stdout/transcripts are never copied wholesale into event history. A reconnect must take a snapshot watermark, read later events, ignore duplicate sequences and resync gaps. Unknown protocol major, release, project, mandatory event or state schema disables mutation.

This proof does **not** yet constitute the project service: the fixture keeps outcomes in memory. It also does not establish Herdr attachment, workflow progression, release routing or native agent isolation. Those belong to subsequent gates in the [milestone-6 proposal](milestone-6-interactive-shell-proposal.md).
